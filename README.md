## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. 서버가 필요 없습니다.

```bash
# 로컬 서버로 열면 PWA(홈 화면 추가 · 오프라인 캐시)까지 동작합니다
python3 -m http.server 8000
# → http://localhost:8000
```

**아이폰에 설치하기**: Safari에서 접속 → 공유 버튼 → *홈 화면에 추가*
전체화면 앱처럼 실행되고, 비행기 안에서도 오프라인으로 동작합니다.
앱을 처음 열면 화면 아래에 설치 안내 배너가 뜨고, 이후에도 **설정 → 앱으로 설치**에서 다시 볼 수 있습니다.

### Cloudflare Pages로 배포하기
빌드 과정이 없는 정적 사이트입니다. 프로젝트 생성 시 아래처럼 설정하세요.

| 항목 | 값 |
|---|---|
| Framework preset | **None** |
| Build command | *(비워둠)* |
| Build output directory | `/` |
| Root directory | *(비워둠)* |

`https://<프로젝트>.pages.dev` 로 접속하면 HTTPS라 서비스워커까지 동작해
아이폰 홈 화면 추가와 오프라인 실행이 모두 정상 작동합니다.

## 기술 구조

```
index.html          앱 셸 (마크업만)
manifest.json       PWA 매니페스트
sw.js               서비스워커 (오프라인 캐시)
css/style.css       디자인 시스템 (Apple HIG · Glassmorphism · 다크/라이트)
js/
  icons.js          Lucide 스타일 인라인 SVG 아이콘 (CDN 없이 오프라인 동작)
  data.js           시드 데이터 (일정 · 기업 · 질문 · 영어 · 가이드 …)
  store.js          LocalStorage 상태 관리 · 통계 · 백업
  ui.js             재사용 컴포넌트 (Toast/Modal/Sheet/Progress/Markdown/사진)
  views.js          화면 (1) 홈 · 일정 · 준비물 · 체크리스트 · 프로젝트
  views2.js         화면 (2) 기업 · 질문 · 영어 · 가이드 · 쇼핑 · 경비 · 일기 · 자료실 · 회의 · 설정
  app.js            라우팅 · 탭바 · 전역 검색 · FAB · 테마 · PWA 등록
```

- 빌드 도구·프레임워크 없이 **바닐라 ES6+**
- 각 화면은 `{ title, sub, render(), mount() }` 인터페이스를 따르는 독립 컴포넌트
- 모든 상태는 단일 LocalStorage 키(`sv-master-v1`)에 debounce 저장
- 사진은 900px로 리사이즈 후 JPEG base64 저장 (용량 절약)
- 입력값은 모두 escape 처리
